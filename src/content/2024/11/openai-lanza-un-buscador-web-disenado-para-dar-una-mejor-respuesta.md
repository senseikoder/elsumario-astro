**El Sumario** - La tecnológica **OpenAI** lanzó un buscador web en **ChatGPT** que está "diseñado para que (el usuario) obtenga una mejor respuesta" sobre resultados deportivos, noticias o cotizaciones de acciones, según apuntó la compañía en un comunicado.

El paso de OpenAI cierra una brecha competitiva clave con rivales como **Microsoft Copilot** o **Google Gemini**, que desde hace tiempo ofrecen acceso a internet en tiempo real en sus chatbots de **inteligencia artificial** (IA).

"ChatGPT ahora puede buscar en la web de una manera mucho mejor que antes. Puede obtener respuestas rápidas y oportunas con enlaces a fuentes web relevantes", precisó la empresa.

ChatGPT elegirá buscar en la web en función de lo que se le pregunte, y además, el usuario puede elegir buscar manualmente haciendo clic en el icono de búsqueda web.

La función está disponible para los usuarios de pago ChatGPT Plus y Team, así como para los usuarios de la lista de espera de SearchGPT.

No obstante, la compañía indica que "en los próximos meses" este buscador se implantará para todos los usuarios.
